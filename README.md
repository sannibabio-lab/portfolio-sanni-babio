# Portfolio professionnel — Dr Sanni BABIO

Site vitrine bilingue français / anglais consacré aux domaines de la géographie, des systèmes d’information géographique (SIG), de l’analyse des données et de l’évaluation des politiques publiques.

## Aperçu

- Site statique HTML/CSS/JavaScript, sans dépendance de compilation.
- Interface bilingue avec bascule FR / EN.
- Mise en page responsive.
- Aucun secret, mot de passe ou jeton n’est requis pour le fonctionnement du site.

## Publication avec GitHub Pages

Dans le dépôt, ouvrir **Settings → Pages**. Dans **Build and deployment**, choisir **Deploy from a branch**, sélectionner **main** et **/(root)**, puis enregistrer.

URL attendue : https://sannibabio-lab.github.io/portfolio-sanni-babio/

## Éléments à compléter avant diffusion professionnelle

- Ajouter la photographie professionnelle, lorsque disponible.
- Ajouter une adresse e-mail professionnelle vérifiée.
- Ajouter les liens LinkedIn et autres profils professionnels confirmés.
- Vérifier les intitulés institutionnels, dates et références bibliographiques à partir des documents sources.
- Ajouter un CV PDF après validation expresse de la version destinée à être publique.

Les informations de contact non confirmées ne sont pas inventées dans cette version.
